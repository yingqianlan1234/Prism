## 2026-11-08 双平台歌单封面

用户反馈网易和 QQ 歌单封面均异常。网易图片地址原样直传，而 CSP 仅允许 HTTPS；若返回 HTTP 则无法加载，但未经真实响应检查，不能认定这是全部或唯一原因。现仅对网易受信任图床将 HTTP 升级 HTTPS，保留原 CSP，缺失或图片失败显示占位。

QQ `map_playlists` 原先未映射任何封面。现提取社区实现可见的 `diss_cover`，以及待实测的 `logo`、`picurl`、`cover` 候选字段；仅接受 QQ、gtimg、qpic 域名并升级 HTTPS，避免扩大 IPC 权限。歌单列表及详情可显示对应封面。参考：https://github.com/jsososo/QQMusicApi/blob/master/routes/user.js （字段和社区实现证据，不代表真实账号验证）。

自动化：22 个 Node 测试及集成脚本通过；随后分别单独运行网易合成 UI 与 QQ 合成 UI 新断言通过。Cargo 51 通过、5 ignored；最终 Release EXE 13,581,312 字节。模拟浏览器检查了缺失封面占位，不涉及真实账户。尚未验证两平台真实账号的封面显示、响应字段是否存在、服务器是否允许实际图片加载。
