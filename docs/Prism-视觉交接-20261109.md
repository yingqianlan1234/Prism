## 三、几个容易踩的坑（重要）

1. **`.lw-library` 的 `overflow` 决定曲库能不能滚**
   它是 `<main>`，本身是滚动容器。第四轮我给它加 `overflow:hidden` 直接把整页滚动锁死了。修法是 `overflow-y:auto; overflow-x:hidden`。

2. **`scrollbar-width` 和 `::-webkit-scrollbar` 不能共存**
   Chromium 里标准属性一生效，整套 `::-webkit-scrollbar` 被忽略，`::-webkit-scrollbar-button` 的隐藏也跟着失效。现在只留 webkit 那套。

3. **伪元素没有 `content` 就完全不生成**
   第六轮删旧光弧规则时连带删掉了唯一的 `content:""`，导致 `::before` 不渲染。`getComputedStyle(el,'::before').transform` 会返回 `none`，**看起来像被规则压制，其实元素根本不存在**。查证要用 CDP 的 `CSS.getMatchedStylesForNode`，不能只看 computed 值。

4. **`conic-gradient` 的 `from` 角度不可插值**
   直接写 `transition: background` 对角度无效，会瞬间跳变。必须用 `@property` 注册 `<angle>` 类型再过渡。

5. **歌词去重不能"同歌 + ready 就跳过"**
   一开始这么写，`platforms.test.mjs` 的「刷新失败不丢在途歌词」直接超时——刷新后重新 `play()` 也被跳过了。现在改成用 `resumedLyric` ref，**只跳过恢复后的第一次点播放**，用完即清。

6. **恢复态 `audio.currentTime` 是 0**
   歌词加载完如果只用它算高亮，会停在第一行。恢复流程要额外传快照里的 `position`。

7. **窗口 zoom 不是 0.8，是系统 DPI 125%**
   `htmlZoom/bodyZoom` 都是 `1`，`devicePixelRatio = 1.25`。CSS 写 `1.5px` 渲染成 1.875 物理像素。读 `outlineWidth` 会看到 `0.8px` 这类值，别误以为被缩放了。
