# 歌词滚动验证记录（2026-11-09）

## 实现

- `src/main.jsx`：根据当前歌词行在歌词容器内的几何位置，滚动到可达的居中位置；通常使用浏览器原生平滑滚动，系统选择减少动态效果时使用直接定位。没有新增常驻动画、轮询或第二个 audio。
- 手动滚轮、触摸、指针或滚动键仍暂停跟随 5 秒；手动操作会中止正在进行的程序滚动。点击“回到当前行”立即恢复跟随并将焦点放回歌词列表。
- `src/lumen.css`：仅有歌词的舞台列表增加首尾留白，便于第一句和最后一句居中；空状态不增加留白。
- 为确保歌词可供滚动，修复恢复歌曲播放时已加载歌词被清空，以及歌词先于音频地址返回时被丢弃的问题；保留请求代次与账号隔离。修复快速图片失败可能被初始化 effect 覆盖的问题。
