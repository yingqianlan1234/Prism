# Prism A10：桌面体验验证

## 已实现

- 窗口内快捷键：空格播放/暂停，Ctrl+左右切歌，Ctrl+上下调音量，Ctrl+L 聚焦搜索，Esc 关闭当前弹窗或先取消清空确认；编辑控件不误触发播放快捷键，非弹窗歌曲按钮获得焦点时空格仍控制播放；弹窗按钮保留原生空格行为。未注册系统全局热键。
- 新增当前浏览平台的队列入口、数量、当前曲目高亮、空状态、逐项移除及清空确认；删除正在播放项或清空当前播放来源时提示并停止，另一个工作区的队列保留。私人 FM 队列不允许普通移除/清空，保留自动续取。队列清空后可持久化空 QQ 队列，网易队列状态独立。
- 歌词清除、加载、空结果和加载失败分别显示；继续在音频进度/seek 事件上同步歌词，不添加持续动画或定时轮询。QQ 104003 显示上游信息，不推断会员或版权状态。
- 单 audio 切歌在获取新源前保留旧状态；首次 `audio.play()` 失败时，只在最新播放令牌和账号代次仍有效时尝试恢复原歌曲、队列、音量和进度。QQ→QQ 时只向受限后端提交两个本地随机句柄并等待恢复结果，绝不传腾讯媒体 URL 或凭据。原 URL/会话过期时提示失败，不宣称必定能恢复；连续 QQ 请求较新结果仍在途时后端可能安全拒绝回滚。新源成功播放以后发生的延迟加载错误不属于本轮首次失败回滚保障。

## 已知边界

首次 play() 失败后恢复是尽力而为：旧地址可能失效、音频加载可能失败，或账号/播放代次变化使恢复安全终止。旧播放源的媒体位置等待 metadata 后恢复，未对实际声卡及播放 URL 做用户端测试。QQ 真实播放仍受 104003 阻碍；不将该实现当作已听到音乐或服务端授权证明。最终主工程自动测试、Rust 测试及独立 Release 构建由合并方执行。

补充单项回归：Ctrl+左右分别触发相邻曲目；QQ 队列确认清空后持久化空队列并停止当前 QQ 音频。合成测试通过；未验证真实 QQ 音频。

补充验证：歌曲按钮真实焦点时空格可暂停/继续且阻止原生重播；弹窗按钮空格保留原生行为。切歌在途禁止修改队列，并提示用户；同步 audio error 使用当前 songRef，合成跨平台测试验证错误归属。退出在途账号时同步清除旧回滚快照；模拟 A→B 待定→QQ C 解析中退出后，再播放失败的 D 不会复用旧 A。
