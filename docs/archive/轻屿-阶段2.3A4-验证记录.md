# 轻屿阶段 2.3 A4：网易听歌记录离线研究与验证

## 范围与源码证据

本轮只实现本地内存计时和模拟候选，不发送网易听歌上报，不创建后台服务或第二音频引擎。对 [Folia 实际源码（固定提交）](https://github.com/chthollyphile/folia-major/blob/90e0210a8144063252974ca5e2403d601de93f41/src/components/app/playback/bridges/usePlaybackReporter.ts)、[计时器](https://github.com/chthollyphile/folia-major/blob/90e0210a8144063252974ca5e2403d601de93f41/src/utils/playbackListenTracker.ts)和 [网易 Provider](https://github.com/chthollyphile/folia-major/blob/90e0210a8144063252974ca5e2403d601de93f41/src/services/onlineMusic/netease/neteaseProvider.ts)进行了只读分析：其以实际媒体进度和墙钟限制计时，默认关闭，仅在登录且在线网易曲目合格时考虑上报；30 秒为 Folia 的应用策略，不是已确认的网易官方规则，云盘、本地及其他来源有排除条件。

Folia 是 [AGPL-3.0](https://github.com/chthollyphile/folia-major/blob/90e0210a8144063252974ca5e2403d601de93f41/LICENSE)，本工程只独立实现一般性的事件和校验逻辑，未复制其代码。其调用的 [社区 scrobble_v1](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/main/module/scrobble_v1.js) 使用登录态并构造 PLV/PLD 两类记录，调用 [客户端日志上传](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/main/util/ncbl.js)，涉及账号、歌曲、实际播放时长和设备/会话上下文。该实现使用非公开协议、加密和客户端上下文；本工程没有接入该上报方案，也不据此认定其适用或获得授权。

## 本轮修改

- `src/listening.js`：无网络、无存储的内存计时器；每个会话绑定平台、账号和歌曲，单调时钟与媒体时间双重校验，30 秒只是本地模拟候选阈值；同一会话只结算一次，进程内相同平台/账号/歌曲只产生一次本地候选。无账号和非网易来源不产生候选。候选不排队、不发送；应用退出后状态清除，同一歌曲长期重复收听的策略仍待设计。
- `src/main.jsx`：将唯一 audio 的播放、进度、暂停、缓冲、拖动、倍速、结束及错误事件接入计时；账号更换时清理旧会话。新增长期方向的上报偏好开关，默认关闭且启动时重置为关闭；显示“未开放”，改变偏好不会发送或授权未来真实上报，中途关闭后再次开启也不会补报当前歌曲。
- `src/listening.test.mjs`、`src/listening-integration.test.mjs`、`src/fm.test.mjs`、`package.json`：覆盖计时、异常跳变、切号、重复、开关、音频事件接线与既有 FM 模拟回归。
