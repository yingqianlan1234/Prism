# 轻屿阶段 2.3 B7：QQ 用户交互式网页登录研究

## 结论：有条件可行

当前没有证据证明轻屿能安全完成 QQ 用户授权并取得音乐会话。只有先确认服务端接受的应用身份和回调，或证明临时授权窗口的权限隔离、会话交接与销毁，才值得投入下一步；否则应停在 QQ 匿名搜索。不要再盲目扫码、自动跟随授权页或把未知页面当作登录成功。本轮没有进行新的 QQ 扫码、真实账号登录、OAuth 请求或凭据读取。

## 三种方案

| 方案 | 分析与结论 |
| --- | --- |
| 系统浏览器 | 符合 [RFC 8252](https://datatracker.ietf.org/doc/html/rfc8252) 外部浏览器优先原则，用户自行确认，应用不读取浏览器 Cookie；但现有社区链路的回调属于 QQ 音乐域，轻屿没有已验证的注册应用身份或可接收回调，也未证明浏览器与 Rust 会话安全交接，因此目前不可宣称可用。不得要求用户复制 Cookie、Token 或完整回调。 |
| 临时隔离授权窗口 | 仅为候选，需证明远程页面没有 Tauri IPC 权限、导航仅限明确的 HTTPS 主机和路径、只由用户操作授权、state/过期/代次严格绑定，关闭销毁临时会话且不影响主窗口音乐；还需证明授权结果能由 Rust 安全接收并换取音乐会话。上述关键证据目前缺失；本轮没有创建窗口或授予权限。 |
| 停止登录接入 | 目前实际采取。保留 QQ 匿名搜索，停用未验证的旧生产扫码入口和登录 IPC，旧源码仅作测试/研究；不自动访问授权页面、不处理验证码或设备校验。 |

## 社区实现与许可边界

[simple-music QQ API 说明](https://github.com/Yyyangshenghao/simple-music/blob/master/docs/qq-music-api.md)区分网页账号状态与音乐播放票据。只读审查其提交 `37c82b2ec1a877a69b2bd6a792aa23fea2c5351a` 的 [login-manager.ts](https://github.com/Yyyangshenghao/simple-music/blob/37c82b2ec1a877a69b2bd6a792aa23fea2c5351a/electron/modules/login-manager.ts) 和 [preload](https://github.com/Yyyangshenghao/simple-music/blob/37c82b2ec1a877a69b2bd6a792aa23fea2c5351a/electron/preload/index.ts)：其使用 Electron 会话分区读取 QQ 域 Cookie，并将登录结果经 IPC 交给渲染侧；这不符合轻屿的临时会话和票据不进前端边界，不能直接照搬。其仓库 [GPL-3.0](https://github.com/Yyyangshenghao/simple-music/blob/master/LICENSE)，本轮未复制实现。

[QQMusicapi 登录源码](https://raw.githubusercontent.com/Suxiaoqinx/QQMusicapi/main/src/modules/login.js)描述二维码、QQ OAuth 和音乐会话交换，也存在设备会话和签名依赖；源码存在不证明当前轻屿可用或有平台授权。正常网页会话是否含音乐密钥、是否有播放授权、是否能恢复，都必须分别实测；本轮均未验证。

## 已实现与安全边界

- `src-tauri/src/qq_login_offline.rs`：离线状态机增加等待用户授权页、等待最终回调状态；页面出现或用户点击并不等于登录成功。合成测试覆盖取消、拒绝、过期、乱序与待验证回调。
- `src-tauri/src/main.rs`：生产构建不注册旧 QQ 登录 IPC、不启动旧 QQ 登录管理对象；旧 `qq_login.rs` 保留为仅测试编译的研究材料。既有 QQ 凭据（如有）没有读取或清理；网易凭据目标保持不变。
- `src/providers.js`、`src/qq-community.js`：QQ 登录、退出、恢复和资料显式 unsupported；匿名搜索继续按固定接口工作。
- `src/main.jsx`：没有 QQ 登录能力时不显示登录入口，工作区以匿名状态可搜索；未改网易播放器实例。
- `src/providers.test.mjs`、`src/qq-community.test.mjs`、`src/qq-login.test.mjs`：模拟验证入口关闭、IPC 未注册、匿名搜索、错误隔离及单音频。`src/main.jsx` 与 A6 诊断修改在主工程逐项串行合并。

严格 HTTPS/主机/路径、唯一 state/code、过期和代次校验仅保留在不启用的研究代码及离线测试中；不能据此声称已经完成安全会话交接。没有向前端或日志输出 Cookie、Token、授权码或完整回调。
