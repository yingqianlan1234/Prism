# Prism 视觉设计阶段准备

当前页面由顶部品牌与工作区切换、横向歌单栏、网易推荐入口、主内容歌曲列表、右侧正在播放和歌词、底部单实例播放器构成。队列、二维码与 QQ 授权使用独立弹层，歌词有侧浮层。界面目前以深中性底、少量浅色强调和文本按钮组织信息。

下一阶段可分别审视歌单导航与分类、歌曲列表密度、专辑封面和播放区域、队列及歌词面板、窄窗口布局；不应为了视觉合并网易与 QQ 数据，或让浏览平台变成播放来源。需保留键盘焦点、清晰的加载/空/错误状态和 FM 独立队列。设计时基于实际截图检查多尺寸、对比度及文本溢出，动态背景应按封面和播放状态服务内容，避免持续无意义动画。

本文件只记录现状与下一阶段范围，不代表已完成视觉重设计或实机视觉验收。
